# 홈페이지 내용 수정하는 방법

글과 사진은 **웹 화면에서 직접** 고칠 수 있습니다. 코드를 건드릴 필요가 없습니다.

---

## 1. 편집 화면 열기

`homepage` 폴더 안의 **`홈페이지 편집.bat`** 파일을 **두 번 클릭**하세요.

- 검은 창이 하나 뜨고, 잠시 뒤 브라우저에 **편집 화면**이 자동으로 열립니다.
- 처음 실행할 때만 준비 작업으로 2~3분 걸립니다. 그다음부터는 10초면 열립니다.
- **검은 창은 편집이 끝날 때까지 닫지 마세요.** (닫으면 편집 화면도 멈춥니다)

브라우저가 자동으로 안 열리면 주소창에 직접 입력하세요 → `http://localhost:3000/admin`

---

## 2. 고치기

왼쪽 메뉴에서 고칠 곳을 고르고, 오른쪽에서 내용을 바꾸면 됩니다.

| 왼쪽 메뉴 | 고칠 수 있는 것 |
|---|---|
| **회사 정보** | 전화번호, 주소, 사업자번호 — 고치면 **모든 페이지**에 한꺼번에 반영 |
| **홈 화면** | 첫 화면 영상·문구, 유튜브 영상, 가운데 카드, PRODUCT 사진 8장 |
| **인사말** | 대표 인사말 본문·사진 |
| **회사연혁** | 연도별 내용 추가·삭제·순서 변경 |
| **사업분야** | 무역·유통·물류·제조 각 항목 |
| **식품제조** | 제조 공정 단계, 제조 품목, 포장 형태·규격 |
| **인증현황** | 인증 목록, 인증서 이미지 |
| **HMR(내수용)** | 납품 제품 52개 — 브랜드·제품명·사진 |
| **그 밖의 제품** | 수입·유지·냉동·소스·면류·수산물·기타 페이지 |
| **고객센터** | OEM 견적 폼 문구, 문의 안내 |

### 사진 바꾸기
사진 옆 **[사진 바꾸기]** 버튼을 누르고 컴퓨터에 있는 사진을 고르면 끝입니다.
(JPG·PNG·WEBP·GIF, 영상은 MP4. 한 개당 40MB까지)

### 항목 추가·삭제·순서 바꾸기
- **+ 항목 추가** — 맨 아래에 새 줄이 생깁니다
- **↑ ↓** — 순서를 위아래로 옮깁니다
- **✕** — 그 항목을 지웁니다

---

## 3. 저장하기

오른쪽 위 빨간 **[저장]** 버튼을 누르세요. (`Ctrl` + `S` 도 됩니다)

- 저장하면 초록색으로 **✓ 저장했습니다** 가 뜹니다.
- 저장하지 않은 수정이 있으면 주황색으로 알려줍니다.
- **저장할 때마다 이전 내용이 자동 백업**됩니다 (최근 30개, `content/_backups` 폴더).

---

## 4. 확인하기

오른쪽 위 **[홈페이지 보기 ↗]** 를 누르면 새 창에서 실제 홈페이지가 열립니다.
고친 내용이 바로 보입니다.

---

## 5. 실제 홈페이지에 올리기

편집 화면에서 고친 내용은 **내 컴퓨터에만** 저장됩니다.
방문자들이 보는 홈페이지에 반영하려면 배포가 필요합니다.

> 배포 방법은 홈페이지를 인터넷에 올린 뒤 별도로 안내드립니다.
> (배포 전이라면 지금은 신경 쓰지 않으셔도 됩니다)

---

## 자주 있는 문제

**Q. 편집 화면이 안 열려요**
→ 검은 창이 떠 있는지 확인하세요. 없으면 `홈페이지 편집.bat` 을 다시 두 번 클릭하세요.

**Q. 실수로 잘못 고쳤어요**
→ 저장 전이면 창을 닫고 다시 열면 됩니다.
→ 저장한 뒤라면 `content/_backups` 폴더에 이전 파일들이 날짜별로 있습니다.

**Q. 사진이 안 올라가요**
→ 파일 크기가 40MB를 넘는지, 형식이 JPG·PNG·WEBP·GIF·MP4가 맞는지 확인하세요.

**Q. 저장 버튼이 회색이에요**
→ 고친 내용이 없으면 회색입니다. 무언가 고치면 빨갛게 바뀝니다.

---

## 참고 — 파일이 어디에 저장되나요

- 글 내용 → `content/site.json`
- 올린 사진 → `public/uploads/` 폴더
- 자동 백업 → `content/_backups/` 폴더

이 파일들을 직접 열어 고칠 수도 있지만, 편집 화면을 쓰는 편이 안전합니다.
