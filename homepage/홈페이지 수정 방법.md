# 홈페이지 수정하는 방법

홈페이지 화면을 **직접 보면서 마우스로** 고칩니다. 코드나 파일 경로를 알 필요가 없습니다.

---

## 1. 편집기 열기

`homepage` 폴더의 **`홈페이지 편집.bat`** 을 **두 번 클릭**하세요.

- 검은 창이 뜨고, 잠시 뒤 브라우저에 **편집기**가 자동으로 열립니다.
- 처음 한 번만 준비 작업으로 2~3분 걸립니다. 이후에는 10초면 열립니다.
- **검은 창은 편집이 끝날 때까지 닫지 마세요.**

자동으로 안 열리면 주소창에 → `http://localhost:3000/admin/editor`

---

## 2. 화면 구성

```
┌──────────────────────────────────────────────────────────┐
│ ← 관리자 │ [페이지▾]    PC 태블릿 모바일    ↺ ↻  미리보기 저장 게시 │
├──────────┬──────────────────────────────┬────────────────┤
│  섹션    │                              │   설정         │
│  목록    │      실제 홈페이지 화면       │  (선택한 것)   │
│ (끌어서  │      (여기서 직접 클릭)       │                │
│  순서)   │                              │                │
└──────────┴──────────────────────────────┴────────────────┘
```

---

## 3. 고치기 — 클릭하면 됩니다

가운데 홈페이지 화면에서 **고치고 싶은 곳을 클릭**하세요.
빨간 테두리로 선택되고, 오른쪽에 그것에 맞는 설정이 나타납니다.

| 클릭한 것 | 오른쪽에서 할 수 있는 일 |
|---|---|
| **글자** | 내용 수정 · 글꼴 · 크기 · 굵기 · 자간 · 행간 · 정렬 · 글자색 · 여백 |
| **사진** | 사진 교체 · 삭제 · 채우기 방식 · 위치 · 확대 · 높이 · 모서리 |
| **영상** | MP4 교체 · 모바일 전용 영상 · 대표 이미지 · 자동재생/반복/음소거 · 어둡게 덮기 |
| **버튼** | 버튼 문구 · 눌렀을 때 갈 주소 |
| **섹션** | 순서 · 숨기기 · 배경색 · 위아래 여백 |

### 글자를 화면에서 바로 고치기
글자를 클릭한 뒤 **[바로 고치기]** 를 누르면 화면 안에서 커서가 생깁니다.
그 자리에서 타자를 치면 됩니다. 다 쓰면 다른 곳을 클릭하거나 `ESC`.

### 사진 바꾸기
사진을 클릭 → 오른쪽 **[사진 바꾸기]** 를 누르거나,
그 자리에 컴퓨터에서 사진 파일을 **끌어다 놓으면** 됩니다.

---

## 4. 섹션 순서 바꾸기 (홈 화면)

왼쪽 **섹션 목록**에서 항목을 **마우스로 잡아 위아래로 끌면** 순서가 바뀝니다.
끄는 동안 들어갈 자리에 빨간 선이 표시됩니다.

- 눈 아이콘 👁 을 누르면 그 섹션을 **숨기거나 다시 보이게** 할 수 있습니다.
- 섹션을 클릭하면 오른쪽에서 배경색과 여백도 조절할 수 있습니다.

---

## 5. PC / 태블릿 / 모바일 확인

위쪽 가운데 **PC · 태블릿 · 모바일** 버튼으로 각 화면에서 어떻게 보이는지 바로 확인합니다.

---

## 6. 잘못 고쳤을 때

- **되돌리기**: `Ctrl` + `Z` (또는 위쪽 ↺ 버튼)
- **다시 실행**: `Ctrl` + `Shift` + `Z` (또는 ↻ 버튼)

---

## 7. 저장과 게시 — 다릅니다 (중요)

| 버튼 | 하는 일 |
|---|---|
| **저장** | 작업 내용만 보관합니다. **실제 홈페이지는 아직 바뀌지 않습니다.** |
| **게시** | 지금까지 작업한 내용을 **실제 홈페이지에 반영**합니다. |

작업하다 중간에 **저장**해 두고, 다 됐을 때 **게시**하세요.
게시할 때는 "홈페이지에 게시하시겠습니까?" 확인 창이 한 번 뜹니다.
게시 직전 내용은 자동으로 백업됩니다.

- 저장하지 않은 수정이 있으면 위쪽에 **저장되지 않은 변경사항** 이라고 표시됩니다.
- 그 상태로 창을 닫으려 하면 경고가 뜹니다.

---

## 8. 방문자 화면 그대로 보기

**미리보기** 를 누르면 편집용 테두리와 버튼이 모두 사라지고,
방문자가 보는 모습 그대로 보입니다. `ESC` 를 누르면 편집으로 돌아옵니다.

---

## 9. 다른 페이지 고치기

왼쪽 위 **페이지 선택 상자**에서 회사소개·제품소개·고객센터 등 원하는 페이지를 고르면
그 페이지가 편집기에 뜹니다. 고치는 방법은 홈 화면과 같습니다.

---

## 자주 있는 문제

**Q. 편집기가 안 열려요**
→ 검은 창이 떠 있는지 확인하세요. 없으면 `홈페이지 편집.bat` 을 다시 두 번 클릭하세요.

**Q. 고친 게 실제 홈페이지에 안 보여요**
→ **게시** 버튼을 눌렀는지 확인하세요. 저장만으로는 반영되지 않습니다.

**Q. 원래대로 되돌리고 싶어요**
→ 게시 전이면 `Ctrl+Z`. 게시한 뒤라면 `content/_backups` 폴더에 날짜별 백업이 있습니다.

**Q. 사진이 안 올라가요**
→ 40MB 이하인지, JPG·PNG·WEBP·GIF·MP4 형식이 맞는지 확인하세요.

## 참고 — 어디에 저장되나요

| 내용 | 위치 |
|---|---|
| 실제 홈페이지에 나가는 내용 | `content/site.json` |
| 작업 중인 내용 (게시 전) | `content/site.draft.json` |
| 올린 사진·영상 | `public/uploads/` |
| 게시 전 자동 백업 | `content/_backups/` |

> 목록형(폼) 편집 화면도 `http://localhost:3000/admin` 에 그대로 남아 있습니다.
> 많은 항목을 한 번에 손볼 때는 그쪽이 편할 수 있습니다.
